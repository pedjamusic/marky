## Entry points and route differences

[Production preparation](../../Marky/MarkdownContentBlocks.swift) extracts document references, identifies blocks and joins paragraph lines. [Inline rendering](../../Marky/MarkdownViewer.swift) then uses the native inline parser. The older `MarkdownRenderer.render(from:)` helper renders each source line independently; it is not the production document route.

The version-1 fixture format gains two optional fields: `legacyRuns` records the whole output of that older helper, and `inlineRuns` records direct `renderInline(from: input)` output without preparation or document reference extraction. Both use the existing complete run format. They are supplementary Mac characterization evidence, not alternative expected core documents. Core consumers use `blocks`. No expected data is generated by a replacement parser.

## Exceptions that need explicit review

- MD-059: `- [x]yes` is an ordinary bullet with literal `[x]yes`; `- [ ] ` is an empty unchecked task. A tab counts as one indentation character, so a single tab gives depth zero.
- MD-062: a single hyphen per delimiter cell is accepted. Do not tighten this to a standards minimum during migration.
- MD-072: composed/decomposed `café` labels both resolve to the same definition. The normalizer uses `lowercased()` and Swift dictionary keys compare canonically equivalent strings; this does not establish full Unicode case folding. `STRASSE` remains unresolved when only `straße` is defined. Visible label spelling is retained exactly.
- MD-073: unknown `&bogus;` and missing-semicolon `&amp` remain literal; null/out-of-range numeric entities become replacement characters. Multi-scalar `&NotEqualTilde;` decodes to `≂` plus combining slash. This sample does not enumerate the native parser's complete entity table.
- MD-077: the nested outer link is not recognized as one link. The inner label is linked, and the remaining visible bare outer URL is independently linked. Link titles are not visible text.
- MD-078: malformed link syntax yields visible `[x](https://example.test/a(b) bad`. The bare URL is linked; `bad` has no destination. This is the observed native fallback, not a new guarantee that every malformed source byte stays visible.
- MD-079–083: a bare destination containing spaces stays source text; nested/escaped alt syntax falls back to paragraph alt text, as does a reference image. A recognized standalone image keeps raw `**raw alt**` and its title as data.
- MD-084–087: HTML source is visible and inert. Ordinary Markdown inside it still receives inline semantics. Tags do not create native bold styling by themselves.

Initial source/test-derived expectations were written before execution. The first executable run corrected MD-059's empty-task expectation and MD-077/078's native malformed-link behavior. A second diagnostic run established MD-045's direct-inline CRLF normalization. Those four revisions are disclosed here rather than described as independently passing unchanged expectations. All other initial new expectations agreed with the observed reader, including the five later table-boundary cases.

## Check changes and limits

The [fixture checks](../../MarkyTests/MarkdownCompatibilityTests.swift) still compare complete semantic projections and actual production container text using byte-encoded JSON, so canonically equivalent Swift strings cannot hide changed scalar spelling. Diagnostics now display synthetic fixture results on mismatch.

Quote semantics previously parsed each line independently. The check now parses the stripped quote body once and splits attributed output at retained LFs, preserving cross-line emphasis (MD-060). It asserts that output lines still map to source quote depths. This line-oriented fixture representation does not claim coverage of code spans that collapse quote line boundaries or delimiter interactions with native nested-quote indicators; those combinations remain receiving T06.S2/T10.S3/T11.S2 coverage obligations. Native quote bars, secondary color and implicit obliqueness are presentation, outside portable traits. Actual production quote text is checked separately, including nesting indicators. No app quote code changed.
